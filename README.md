# 🌾 融小通（RongXiaoTong）农业综合服务平台

> 以农户为中心，整合**银行融资授信、农产品线上购销、农业技术咨询指导**三大业务，
> 通过智能匹配算法实现融资、销售、农技服务一体化，完成多方业务协同，助力乡村振兴。

## 📌 项目简介

融小通是一个面向"三农"场景的综合服务平台，共 **7 大功能模块**，围绕 **4 类核心角色**（农户、银行、买家、技术专家）打通三条业务线：

| 业务线 | 参与方 | 核心流程 |
|--------|--------|----------|
| 融资业务 | 农户 ↔ 银行 | 农户申请贷款 → 算法**智能匹配联合贷款农户** → 银行侧**智能匹配农户**、贷款审批 → 生成融资信息 |
| 农产品产销 | 农户 ↔ 买家 | 农户管理商品 / 查看采购需求；买家浏览商品、购物车下单 / 发布求购需求 |
| 农技增值服务 | 农户 ↔ 技术专家 | 专家维护农业知识库；农户提问 → 专家回答；农户预约专家 → 专家处理预约 |

## 🧩 功能模块

| 模块 | 主要功能 |
|------|----------|
| 首页 | 新闻轮播、金融产品展示、专家一览、专家问答展示、农业知识展示、助农电商入口 |
| 融资服务 | 贷款产品一览、贷款申请、**智能匹配联合贷款人（Top3 + 推荐理由）** |
| 专家助力 | 农业知识浏览（专家维护知识库）、农业问答、专家介绍、在线咨询（消息对话）、预约专家 |
| 农产品交易 | 商品浏览（搜索/分类/详情）、购物车、提交订单（扣库存/取消恢复）、求购需求大厅 |
| 个人信息 | 基础信息 + 头像上传、收货地址、密码修改、我的发布；按角色集成专家信息管理、我的订单、我的融资、用户管理、商品管理等子功能 |
| 融资管理（银行侧） | 银行专属后台：**智能匹配农户（Top10 + 推荐理由）**、贷款审批（通过/拒绝 + 农户通知） |
| 通知中心 | 全局红点提醒：未读消息、新订单、已发货、问题已回答、预约处理、审批结果（10 秒轮询） |

## 🛠 技术栈

| 层 | 技术 |
|----|------|
| 后端 | Spring Boot 3.5.3（Java 17）、MyBatis-Plus 3.5.7、SQLite、Hutool（JWT 令牌 + BCrypt 密码加密） |
| 前端 | Vue 3、Vite、Element Plus、Pinia、Vue Router、Axios |
| 架构 | 前后端分离；JWT 登录态（拦截器校验）；统一返回格式 `Result{code,msg,data}`；全局异常处理；本地文件上传 |

**两个智能匹配算法**（核心亮点）：
1. **联合贷款人匹配**：信用分 40% + 还款能力 30% + 地域相近 20% + 历史合作 10%，加权打分 Top3
2. **银行侧农户匹配**：信用分 40% + 种植规模 30% + 历史履约 30%，加权打分 Top10

（算法实现见 `backend/src/main/java/com/rongxiaotong/service/MatchService.java`，带详细注释）

## 🚀 快速启动

### 1. 启动后端（端口 8080）

```bash
cd backend
mvn spring-boot:run
```

看到 `融小通平台后端启动成功：http://localhost:8080/api` 即启动完成。
首次启动会自动创建数据库文件并写入演示数据（`db/init.sql`），无需手动建库建表。

### 2. 启动前端（端口 5173）

```bash
cd frontend
npm install        # 仅首次需要，安装依赖
npm run dev
```

### 3. 浏览器访问

打开 **http://localhost:5173** 即可使用平台。

## 🗄 数据库说明

- 数据库文件：`backend/rongxiaotong.db`（可用 SQLiteStudio 直接打开查看）
- 建表与种子数据：`backend/src/main/resources/db/init.sql`（幂等脚本，每次启动自动执行，不会重复插入）
- 主要数据表：用户、农户档案、专家信息、收货地址、新闻、贷款产品、贷款申请、联合贷款人、匹配记录、知识文章、问答、回答、预约、咨询消息、商品、求购需求、购物车、订单、订单明细、系统通知
- **重置数据**：停止后端 → 删除 `rongxiaotong.db` → 重新启动（自动重建并写入种子数据）

## ❓ 常见问题

| 问题 | 解决 |
|------|------|
| 后端启动报"Port 8080 was already in use" | 端口被占用：`netstat -ano \| findstr :8080` 找到 PID 后 `taskkill /PID <pid> /F` |
| 前端页面空白 | 先看浏览器 F12 控制台报错；确认后端已启动；Ctrl+F5 强制刷新清缓存 |
| Maven 依赖下载慢 | 已配置阿里云镜像（`~/.m2/settings.xml`），如换机器需重新配置 |
| 想换回 MySQL | 将 `pom.xml` 中 `sqlite-jdbc` 替换为 `mysql-connector-j`，修改 `application.yml` 数据源配置即可，实体与业务代码无需改动 |
