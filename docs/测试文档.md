> 面向测试人员：包含全部模块功能清单 + 可逐步执行的测试工作流。

## 一、测试环境准备

1. 启动后端：`cd backend && mvn spring-boot:run`（端口 8080）
2. 启动前端：`cd frontend && npm run dev`（访问 http://localhost:5173）
3. 浏览器开两个窗口（或用无痕窗口），一个登录**业务发起方**、一个登录**业务接收方**，用于测试协作流程
4. 如需重置数据：停止后端 → 删除 `backend/rongxiaotong.db` → 重启后端

## 三、模块功能清单

| 模块 | 已实现功能 |
|------|-----------|
| **用户系统** | 注册（4 角色选择，注册即登录）、登录、退出、JWT 登录态、角色差异化跳转（银行→后台）、账号禁用后无法登录 |
| **首页** | 新闻轮播、金融产品展示、专家一览、专家问答展示、农业知识展示、助农电商入口（六板块均可点击跳转） |
| **融资服务** | 贷款产品一览、贷款申请（金额/期限/用途校验）、**智能匹配联合贷款人**（信用40%+还款能力30%+地域20%+历史合作10%，Top3+维度得分+推荐理由）、我的融资列表 |
| **专家助力** | 知识库浏览（分类/分页/详情浏览量+1）、专家维护知识（发布/编辑/删除）、在线问答（提问/回答/删除，删回答后问题回待回答）、专家一览/详情、在线咨询聊天（3 秒轮询+已读）、预约专家（提交/确认/完成/取消+服务次数累加） |
| **农产品交易** | 商品浏览（搜索/分类/分页/详情含产地）、农户商品管理（发布/编辑/上下架/删除）、购物车（加购/改数量/删除/勾选）、下单结算（收货地址选择/新增、按农户拆单、扣库存、清购物车）、订单流转（付款/发货/取消恢复库存）、求购大厅（买家发布/管理，农户查看买家电话） |
| **个人信息** | 基础信息+头像上传、收货地址管理（增删改/设默认）、密码修改（校验原密码，改后重登）、我的发布（按角色聚合：商品/需求/知识+删除）、专家信息管理、我的融资、用户管理（管理员：搜索/启禁用/角色统计） |
| **融资管理（银行侧）** | 银行专属后台（非银行角色拦截）、工作台统计、**智能匹配农户**（信用40%+种植规模30%+历史履约30%，Top10+理由）、匹配记录+标记已联系、贷款审批（通过/拒绝+确认弹窗） |
| **通知中心** | 铃铛红点（10 秒轮询）、未读消息、新订单（农户）、待发货提醒（付款后）、已发货（买家）、问题已回答、预约状态更新、审批结果、点击通知跳转对应页+已读、全部已读 |
| **权限控制** | 未登录访问需登录页面→跳登录（登录后回跳原页面）、角色不符操作被拒（如买家不能申请贷款、非银行不能进后台） |

## 四、测试工作流

### 工作流 1：用户系统

1. 打开 http://localhost:5173，点击右上角「登录 / 注册」
2. 切到「注册」标签，选择身份「农户」，填写账号（如 farmer99）、密码 123456、姓名、手机号 → 点「注册并登录」
   - ✅ 提示注册成功，自动登录，右上角显示头像和姓名
3. 退出登录 → 用刚注册的账号登录
   - ✅ 登录成功进入首页
4. 用错误密码登录
   - ✅ 提示「账号或密码错误」
5. 登录 farmer01 → 个人中心 → 修改密码：原密码 123456 → 新密码 654321
   - ✅ 提示修改成功并跳转登录页；用 654321 能登录、123456 不能
   - ⚠️ 测完请改回 123456，保持种子账号一致
6. 未登录状态点击「个人中心」
   - ✅ 跳转登录页；登录成功后自动回到个人中心
7. admin 登录 → 个人中心 → 用户管理 → 禁用 farmer99
   - ✅ 列表状态变「已禁用」；farmer99 无法再登录

### 工作流 2：融资业务闭环（农户 ↔ 银行）⭐

前置：窗口 A 登录 farmer01，窗口 B 登录 bank01。

1. A 窗口：融资服务 → 查看 3 个贷款产品 → 点「申请贷款」
2. 填金额、期限、用途 → 点「下一步：智能匹配」
   - ✅ 展示 Top3 联合贷款人：李建国（信用优秀，与你同市）排第一，每人有 4 个维度进度条和推荐理由
3. 选择李建国 → 提交申请
   - ✅ 提示"申请提交成功"；页面下方「我的融资申请」出现新记录（待审批）
4. B 窗口：自动进入银行后台 → 「✅ 贷款审批」→ 看到这笔待审批申请（含农户姓名电话、金额、联合人）
5. 点「通过」
   - ✅ 弹出确认框；确认后状态变「已通过」
6. 切回 A 窗口：10 秒内铃铛出现红点 → 点开看到「🎉 贷款审批通过」→ 点通知
   - ✅ 跳转「我的融资」，该申请状态显示「已通过」
7. A 窗口再申请一笔，B 窗口点「拒绝」
   - ✅ 农户收到「贷款审批结果」通知，我的融资显示「已拒绝」
8. 银行后台侧边栏「贷款审批」红点数字随审批减少
   - ✅ 无需刷新页面，10 秒内自动更新

### 工作流 3：农产品交易闭环（买家 ↔ 农户）⭐

前置：窗口 A 登录 buyer01，窗口 B 登录 farmer01（买王志强的商品）。

1. A 窗口：农产品交易 → 搜索"面粉" → 点进「石磨面粉 5kg」详情
   - ✅ 详情显示价格、库存、供货农户、产地
2. 数量选 2 → 「加入购物车」→ 右上角购物车图标出现红点数字
3. 进购物车 → 修改数量为 3 → 点「去结算」
   - ✅ 弹出地址选择框（已有默认地址"陈明"）
4. 试一下「新增收货地址」填写后保存 → 选中新地址 → 提交订单
   - ✅ 提示下单成功，跳转订单页，订单状态「待付款」
5. 点「付款」
   - ✅ 状态变「待发货」；B 窗口 10 秒内铃铛红点 → 「🚚 待发货提醒」（注意：下单时不通知，付款后才通知）
6. B 窗口：点通知跳转供货订单 → 看到该订单（买家陈明、商品明细、收货地址）→ 点「发货」
   - ✅ 状态变「已完成」；A 窗口收到「订单已发货」通知
7. 验证库存：A 窗口回到商品详情
   - ✅ 石磨面粉库存比下单前减少 3（下单前记一下库存数）
8. 取消场景：A 再下一单 → 付款 → 在「待发货」状态点「取消订单」
   - ✅ 取消成功（未发货前均可取消）；商品库存恢复
9. 求购需求：A 窗口 → 求购大厅 → 发布一条需求；B 窗口（农户）查看 → 点「联系买家」
   - ✅ 弹出买家姓名和电话
10. B 窗口：农产品交易 → 切「我的商品管理」→ 发布一个新商品 → 上架/下架切换
    - ✅ 商城列表实时同步；下架商品在商城中消失

### 工作流 4：农技服务闭环（农户 ↔ 专家）⭐

前置：窗口 A 登录 farmer01，窗口 B 登录 expert01。

1. A 窗口：专家助力 → 知识库 → 点一篇文章
   - ✅ 显示标题、专家、浏览量（+1）
2. B 窗口：知识库 → 切「我的知识管理」→ 发布一篇新知识 → 编辑 → 删除
   - ✅ 三个操作均成功，浏览列表实时同步
3. A 窗口：问答页 → 「我要提问」→ 填标题描述（可选指定专家）→ 提交
   - ✅ B 窗口「待回答」标签出现红点数字，能看到该问题
4. B 窗口：点「去回答」→ 填写回答 → 提交
   - ✅ A 窗口 10 秒内铃铛红点 → 「问题已有专家回答」→ 点通知跳问答页看到回答
5. 删除功能：B 在问答详情中删除自己的回答
   - ✅ 该问题回到「待回答」列表；A 在「我的提问」删除该问题 → 全部消失
6. 在线咨询：A 窗口 → 专家团队 → 点刘建华 → 「在线咨询」→ 发消息
   - ✅ B 窗口铃铛红点 → 点消息进入聊天页 → 回复；A 窗口 3 秒内收到回复（消息已读后红点消失）
7. 预约：A 窗口 → 专家详情 → 「预约专家」→ 填主题和时间 → 提交
   - ✅ B 窗口铃铛显示「预约待处理」→ 进预约管理 → 点「确认」→ A 收到「预约已确认」通知；B 再点「完成」→ 专家详情页服务次数 +1

### 工作流 5：个人中心（按角色）

1. farmer01 → 个人中心 → 基础信息 → 上传一张本地图片 → 保存

   - ✅ 操作均成功，默认地址标记正确

   - ✅ 显示自己的商品列表，可删除
4. buyer01 → 我的发布
   - ✅ 显示自己的求购需求列表
5. expert01 → 专家信息管理 → 修改职称和介绍 → 保存
   - ✅ 专家团队页看到更新后的介绍
6. expert01 → 个人中心左侧菜单
   - ✅ 菜单包含：基础信息/修改密码/收货地址/我的发布/专家信息管理/预约管理/知识管理（与农户、买家的菜单不同）
7. admin → 用户管理 → 搜索"farmer" → 查看各角色人数统计
   - ✅ 搜索过滤生效，统计数字正确

### 工作流 6：权限与异常（边界测试）

1. 未登录直接访问 http://localhost:5173/bank
   - ✅ 跳转登录页；登录 farmer01 后再访问 /bank → 提示"只有银行账号可以进入"并回首页
2. 用 farmer01 打开农产品交易 → 点「申请贷款」（融资服务页）
   - ✅ 农户可正常申请；用 buyer01 点申请 → 提示"只有农户可以申请贷款"
3. 用 expert01 点「加入购物车」
   - ✅ 提示"只有买家可以购买商品"
4. 贷款申请金额填超出产品额度范围
   - ✅ 提示金额须在额度范围内，无法提交
5. 购物车数量改为超过库存
   - ✅ 提示库存不足
6. 重复注册同一账号
   - ✅ 提示"该账号已被注册"
